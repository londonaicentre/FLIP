# The monai floor is 1.6.0 and torch is pinned to a specific cu128 build. Both lines are
# deliberate, for different reasons:
#   * monai < 1.6.0 carries four high-severity advisories patched only in 1.6.0 (NumpyReader and
#     algo_from_pickle deserialization RCE, unsafe pickle use, OS command injection), and 1.6.0 is
#     also what FLIP trains with (flip-utils), so a directory bundle rebuilds its architecture under
#     the same MONAI that produced the weights. 1.5.0, the version inherited from the App SDK's own
#     example, additionally declares torch<2.7.0 — and torch <2.7 has no sm_120, so a MAP built that
#     way cannot use a Blackwell GPU while torch.cuda.is_available() still returns True.
#   * the +cu128 local version is what keeps this MAP runnable on hosts with an NVIDIA driver older
#     than 580: PyPI's default torch wheel is cu130, which needs >= 580. cu128 wheels run on newer
#     drivers too, so it is the conservative choice, at the cost of capping torch at 2.11.0 (the
#     last cu128 build PyTorch publishes).
--extra-index-url https://download.pytorch.org/whl/cu128
torch==2.11.0+cu128
